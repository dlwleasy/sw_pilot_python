학습목표: 시스템 정보

수행과제


class MissionComputer 클래스에 추가
- 미션 컴퓨터의 정보 알아보기 : get_mission_computer_info
- 정보: 운영체제, 운영체제 버전, cpu 타입, cpu 코어 수, 메모리 크기 
- json 형식으로 가져온 시스템 정보 출력하는 코드
- 부하를 가져오는 코드 : get_mission_computer_load()
- 정보 : CPU 실시간 사용량, 메모리 실시간 사용량
- 해당 결과를 JSON 형식으로 출력하는 코드를 추가한다.

- 두 함수 모두 잘 출력되는지 확인

인스턴스화
- MissionComputer 클래스를 runComputer 라는 이름으로 
- 두 메소드를 호출해서 시스템 정보에 대한 값을 출력 할수 있도록 한다.

- 최종 : mars_mission_computer.py 에 저장한다.
 
제약사항
- 시스템 정보가져오는 라이브러리
- 시스템 정보를 가져오는 부분은 예외처리가 되어 있어야 한다.
- 모든 라이브러리는 안정된 마지막 버전을 사용해야 한다.

보너스 과제
- setting.txt 파일을 만들어서 출력되는 정보의 항목을 셋팅 할 수 있도록 코드를 수정한다.
