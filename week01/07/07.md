# 학습목표: 터미널 출력, time

# 수행과제

- 미션 컴퓨터에 해당하는 클래스  MissionComputer 정의

- 화성 기지의 환경에 대한 값을 저장할 수 있는 사전(Dict) 객체
env_values

- 속성 

-  DummySensor 클래스를 ds라는 이름으로 인스턴스화 
- MissionComputer에 get_sensor_data() 메소드를 추가

- get_sensor_data() 메소드에 다음과 같은 세 가지 기능을 추가한다.
1. 센서의 값을 가져와서 env_values에 담는다.
2. env_values의 값을 출력한다. 
3. 이때 환경 정보는 값은 json 형태로 화면에 출력한다.
위의 두 가지 동작을 5초에 한번씩 반복

- MissionComputer 클래스를 RunComputer 라는 이름으로 인스턴스화 한다.

RunComputer 인스턴스의 get_sensor_data() 메소드를 호출해서 지속적으로 환경에대한 값을 출력 할 수 있도록 한다.

전체 코드를 mars_mission_computer.py 파일로 저장한다.

# 제약사항
시간을 다루는 라이브러리는 사용 가능하다.


# 보너스 과제

특정 키를 입력할 경우 반복적으로 출력되던 화성 기지의 환경에 대한 출력을 멈추고‘Sytem stoped....’ 를 출력 할 수 있어야 한다.

5분에 한번씩 각 환경값에 대한 5분 평균 값을 별도로 출력한다.
