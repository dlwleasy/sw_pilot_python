수행과제

- mission_computer_main.log 파일을 읽어들여서 출력한다.
- 콤마를 기준 날짜 및 시간과 로그 내용을 분류 후 리스트(List) 객체로 전환 및 출력
- 리스트 객체 시간 역순 정렬
- 사전 객체로 전환
- 사전 객체 내용 -> mission_computer_main.json 파일로 저장

제약사항

- 기본 명령어 사용
- 파일처리 : 모두 예외처리
- json 포맷 구현

보너스 과제
사전 객체로 전환된 내용에서 특정 문자열 (예를 들어 Oxygen)을 입력하면 해당 내용을출력하는 코드를 추가한다.
