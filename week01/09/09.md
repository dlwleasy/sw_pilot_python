학습목표: Threding, Multi process

수행과제

- 두 개의 메소드 20초에 한번씩 결과를 출력 할 수 있게 수정한다.
- runComputer 인스턴스의 3개 메소드를 각각 멀티 쓰레드로 실행 시킨다.

- 다시 코드를 수정해서 MissionComputer 클래스를 runComputer1, runComputer2,runComputer3 이렇게 3개의 인스턴스를 만든다.
- 3개의 인스턴스를 멀티 프로세스로 실행시켜서 각각get_mission_computer_info(),get_mission_computer_load(),get_sensor_data()를 실행시키고 출력을 확인한다.

- 결과 : mars_mission_computer.py 에 저장한다.

보너스 과제

멀티 쓰레드와 멀티 프로세스에서 반복적으로 출력되는 중간에 특정한 키를 입력 받아출력을 멈출 수 있게 코드를 작성한다.
